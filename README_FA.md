# Hotspot Guardian Safe (Samsung Galaxy A35)

برنامه بسیار سبک برای **هشدار قطع ارتباط محلی با هات‌اسپات**، بدون روت یا تغییر تنظیمات گوشی.

**محدودیت مهم:** برنامه اندروید معمولی نمی‌تواند تضمین کند سیگنال SSID هات‌اسپات همیشه فعال بماند یا در صورت هنگ‌کردن، Wi-Fi را خودش تعمیر کند. این برنامه فقط دریافت پیام‌های دوره‌ای لپ‌تاپ از صفحه محلی را کنترل می‌کند.

## نصب APK

1. از صفحه **Actions** این مخزن، گردش‌کار موفق **Build safe Android APK** را باز کن.
2. پایین صفحه در **Artifacts** فایل `HotspotGuardianSafe-1.0-debug-APK` را دانلود کن.
3. فایل ZIP دانلودی را Extract کن؛ داخل آن `app-debug.apk` است.
4. APK را روی A35 نصب کن. این فایل با **کلید تست Debug** امضا می‌شود؛ نسخه انتشار عمومی نیست.

## نحوه استفاده

1. هات‌اسپات گوشی را از تنظیمات سامسونگ روشن کن.
2. برنامه را باز کن و **شروع پایش** را بزن. مجوز اعلان را تأیید کن.
3. آدرس `http://IP:8765/` نمایش‌داده‌شده را در مرورگر لپ‌تاپ متصل به هات‌اسپات باز کن.
4. تب را باز نگه دار؛ مرورگر هر ۱۲ ثانیه پیام کوچکی به گوشی می‌فرستد. اگر بیش از ۹۰ ثانیه نرسد، گوشی هشدار می‌دهد.
5. با دکمه **توقف کامل پایش** یا گزینه اعلان می‌توانی سرویس را متوقف کنی.

اگر آدرس نشان داده نشد، اندروید ممکن است IP رابط SoftAP را در دسترس برنامه قرار نداده باشد. اگر مرورگر به خواب برود، ممکن است هشدار کاذب ایجاد شود.

## حریم خصوصی / خطرات

- هیچ مجوز ذخیره‌سازی، مکان‌یابی، روت، مدیریت دستگاه، Accessibility، VPN یا تغییر تنظیمات Wi-Fi ندارد.
- برنامه کد نوشتن/پاک‌کردن فایل، دیتابیس، SharedPreferences یا لاگ ندارد. هیچ سرور اینترنتی یا SDK تبلیغات ندارد.
- فقط IP محلی گوشی را روی پورت ۸۷۶۵ گوش می‌کند و وضعیت دستگاه‌ها را موقتاً در RAM نگه می‌دارد. تمام دستگاه‌های روی همان شبکه محلی قادرند صفحه محلی را باز کنند.
- ثبت‌های داخلی سیستم‌عامل، تاریخچه مرورگر یا کش سیستم **تحت کنترل برنامه نیستند**؛ صفر مطلق فایل/لاگ در کل دستگاه قابل تضمین نیست.
- سرویس به‌صورت خودکار پس از ری‌استارت گوشی شروع نمی‌شود.
- لپ‌تاپ باید صفحه را باز نگه دارد و این روش «پایش اتصال» است، نه پیشگیری قطعی از اختلال SSID.

## ساخت و تست

Java 17, Gradle 8.11.1, Android Gradle Plugin 8.9.2, compileSdk 35. GitHub Actions هر Push روی main و اجرای دستی را تست و Build می‌کند. فرمان‌ها:

```bash
bash tests/run_local_tests.sh
gradle :app:assembleDebug :app:lintDebug
```

تست‌های ماشینی مانفیست، APIهای مخرب یا نوشتن فایل، منطق ۹۰ ثانیه، reconnect و حداکثر چهار دستگاه را بررسی می‌کنند. کامپایل Android و lint روی GitHub Actions انجام می‌شود؛ نصب واقعی روی Galaxy A35 نیازمند تست روی خود گوشی است.
