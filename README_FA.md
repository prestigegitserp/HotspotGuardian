# Hotspot Guardian نسخه ۳ — راهنمای فارسی

**این فایل برای نسخه جدید به‌روزرسانی شده است.**

هیچ HTML یا آی‌پی لپ‌تاپ لازم نیست. داخل خود گوشی، پس از فعال‌کردن دسترسی اختیاری Accessibility، گزینه «بازیابی همین الان» را بزن تا برنامه تلاش کند کلید Mobile Hotspot را از پنل سریع سامسونگ خاموش و روشن کند.

دسترسی را از دو دکمه داخل اپ تنظیم کن: «۱. بازکردن اطلاعات برنامه» (در صورت نیاز Allow restricted settings از منوی سه‌نقطه)، سپس «۲. بازکردن Accessibility» و فعال‌کردن سرویس Hotspot Guardian در Installed apps.

بازیابی دوره‌ای **اختیاری** در بازه‌های ۳۰/۶۰/۱۲۰ دقیقه است و حتی روی ارتباط سالم می‌تواند قطعی ایجاد کند. پیش‌فرض خاموش است. در صورت قفل امن گوشی، بازیابی تا بازشدن عادی قفل عقب می‌افتد.

برنامه بدون ROOT، بدون اینترنت، بدون ساخت لاگ/دیتابیس و بدون پاک‌کردن فایل کار می‌کند. سیستم‌عامل می‌تواند کش یا لاگ مستقل داشته باشد.

**تضمینی برای تعمیر هنگ فریم‌ور Wi-Fi/SoftAP گوشی وجود ندارد.** اگر کلید هات‌اسپات سامسونگ با اطمینان قابل تشخیص نباشد، برنامه از لمس حدسی خودداری می‌کند.
