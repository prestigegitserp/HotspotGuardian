# Hotspot Guardian v3 — One-Phone Recovery for Samsung Galaxy A35

**No laptop, no HTML, no IP addresses, no web server, no heartbeats.** The previous network-monitor implementation and companion page were intentionally removed.

## What it actually does

- **Recover now** (primary button): After the user grants optional Android Accessibility access, the app opens Samsung Quick Settings, recognizes the **Mobile Hotspot** tile **and its ON/OFF state**, and attempts an OFF → ON cycle. The app refuses guessed taps if the tile or its state cannot be verified. If the hotspot is OFF, the *manual* command may switch it ON.
- **Optional maintenance**: User explicitly opts in to try this same refresh every 30, 60 or 120 minutes. This can interrupt *healthy* connections and is OFF by default. A scheduled action never turns ON a hotspot that was intentionally OFF.
- **Locked screen**: The app does not unlock or bypass Android Keyguard. A due refresh is deferred until the next ordinary user unlock; it cannot guarantee autonomous recovery while locked.
- **Safety**: No root, ADB, Shizuku, accessibility screenshots, VPN, INTERNET permission, local server, data/files/cache deletion, persistent logs, analytics or cloud traffic. Android itself may create routine operational caches/logs.

**Important:** Android does not expose a reliable unprivileged API for discovering whether the phone's own SoftAP SSID is actually broadcasting. We therefore do not falsely claim to detect/fix a dead SSID, and scheduled refresh is explicitly prophylactic rather than event-triggered. The Samsung UI may vary by One UI version or layout; if the tile is not discoverable, this app stops without an unverified click.

## APK download

Open the latest successful [Build safe Android APK](https://github.com/prestigegitserp/HotspotGuardian/actions/workflows/build-apk.yml) run and download the artifact **HotspotGuardian-v3-OnePhone-APK**. Extract `app-debug.apk` from the ZIP.

The debug keystore is generated by GitHub Actions per run. Because different builds can have different debug signing keys, Android may refuse to update from an older build until that *app only* is uninstalled.

## How to enable Accessibility on a sideloaded APK

1. Open the app; tap **۱. بازکردن اطلاعات برنامه**.
2. If available, in **App info** tap the three-dot menu and **Allow restricted settings**.
3. Return to the app, tap **۲. بازکردن Accessibility**. Under **Installed apps** enable the **Hotspot Guardian** service.
4. Return to the app: its permission status must show **دسترسی بازیابی فعال است**. Then use **بازیابی همین الان**.

Android's restricted-settings protections exist for a reason: Accessibility is powerful. Only enable it after reviewing and trusting this source.

## Tests and limitations

GitHub Actions runs policy boundary unit tests, static analysis for dangerous APIs and permissions, Android build and Android Lint. A successful CI run proves compilation and selected regression checks only; it does NOT prove the Mobile Hotspot tile is reachable on your physical Galaxy A35. Use manual recovery first and observe results before optionally enabling periodic maintenance.

Stop recurring refresh at any time from the in-app STOP button or notification.
